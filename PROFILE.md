# Odds API

OpenAPI-first sports betting odds API (odds-api.net) providing bookmaker odds, odds comparison, arbitrage, positive EV, line movement, and racing/sports coverage via REST plus SSE and WebSocket streaming. Agent-native with an MCP server, llms.txt, and agent instruction files, plus TypeScript and Python SDKs.

## APIs

- **Odds API REST** — REST API for sports and racing betting odds with SSE and WebSocket streaming, arbitrage, positive EV, line movement, bookmaker comparison, and results. API-key auth via X-API-Key. (`https://api.odds-api.net/v1`)

> REST API confirmed at https://api.odds-api.net/v1 with X-API-Key auth; canonical OpenAPI 3.1 served live at /v1/openapi.json (also in GitHub repo as openapi.json/openapi.yaml) with hosted reference UI at /v1/reference. Postman collection, llms.txt, and agent instruction files (AGENTS.md, agents/AGENTS.md) confirmed. MCP server is distributed as a locally-run npm package (npx @odds-api/mcp over stdio) — NOT a hosted public MCP endpoint, so no MCPServer property is cataloged; it does offer optional server-side stream broker tools but connects to the API rather than exposing a public MCP URL. agent_native=true is driven by the hosted llms.txt and published agent skills. Streaming (SSE /odds/stream, WebSocket wss:.../odds/ws) is documented within OpenAPI/docs; no AsyncAPI or GraphQL is published. Note: submitted apis.json lists baseURL https://odds-api.net (marketing/docs host) but operational API base is https://api.odds-api.net/v1. Provider is distinct from the-odds-api.com and odds-api.io.
