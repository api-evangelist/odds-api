## Main Endpoints

- `GET /v1/bookmakers` - supported bookmakers, country coverage, and feed availability.
- `GET /v1/coverage` - bookmaker, sport, league, and approximate market coverage.
- `GET /v1/events` - upcoming fixtures with league, team, start-time, and status metadata.
- `GET /v1/events/{event_id}/odds/snapshot` - pre-match bookmaker prices for moneylines, spreads, totals, and related markets.
- `GET /v1/events/{event_id}/odds/history` - retained pre-match selection history for enabled accounts.
- `GET /v1/racing/events` - horse, harness, and greyhound race discovery.

## Agent Notes

- Use `ODDS_API_KEY` for authenticated API calls.
- Use `ODDS_API_BASE_URL=https://api.odds-api.net/v1` for SDKs and examples.
- Prefer the OpenAPI document for exact schemas and parameter contracts.
- Public package names are `@odds-api/client`, `@odds-api/mcp`, and `odds-api-client`.
